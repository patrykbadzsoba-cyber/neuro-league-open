# StayFlow — Hotel Guest Portal

A white-label, mobile-first guest portal concept intended for independent hotels internationally.

## Prototype

Open `index.html` in a browser. The interface currently includes:
- English, Polish, German, Portuguese, Dutch and Danish UI copy
- Hotel information tiles (reception, arrival/departure, Wi-Fi, dining, local guide)
- Guest request form
- Local-only demo request list
- Responsive layout for mobile and desktop

## Important status

This is a front-end concept prototype. It is **not** connected to a production database, hotel PMS, booking engine, payment provider, email/SMS gateway or staff authentication. Guest requests are held only in the current browser session and are not transmitted to a hotel.

## Production work required

1. Hotel-specific tenant configuration and branding.
2. Secure staff dashboard with authentication and role-based permissions.
3. Server-side request storage, delivery and status tracking.
4. PMS / booking-engine integration where authorised by the hotel.
5. Privacy notice, data minimisation, retention and GDPR review.
6. Accessibility, security and cross-device testing.

## Product direction

Offer the portal as a configurable subscription or licensed service to hotels in multiple countries. Each hotel receives its own branded guest page, language configuration, service links and operational dashboard.
